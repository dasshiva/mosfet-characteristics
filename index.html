Theory

Inside the common-source stage

Circuit under test

Figure 1. NMOS common-source test circuit. VGS sets the channel; RD converts drain current into a drain voltage.

01

Cutoff

When VGS ≤ Vth, no inversion channel forms. ID ≈ 0 and the drain sits at VDD.

02

Triode

For VDS < VGS − Vth, the channel is continuous and the device behaves like a voltage-controlled resistor.

03

Saturation

Once VDS ≥ VGS − Vth, the channel pinches off near the drain. ID is set mainly by VGS, with a mild λ slope.

04

Load line

The external circuit imposes ID = (VDD − VDS)/RD. Its intersection with the device curve is the Q point.

Lab procedure

How the measurement is made

  1. 01

    Set the gate bias

    Hold VGS at a fixed value above Vth and verify the gate current is negligible.

  2. 02

    Sweep the drain supply

    Increase VDS from 0 V in small steps and record ID after each step settles.

  3. 03

    Repeat for each VGS

    Build the output family by repeating the sweep for several gate voltages.

  4. 04

    Fix VDS and sweep VGS

    With VDS in saturation, vary VGS and record ID to obtain the transfer characteristic.

  5. 05

    Extract the parameters

    Find Vth from the turn-on point, kn from the square-law fit, and gm from the slope of the transfer curve.
